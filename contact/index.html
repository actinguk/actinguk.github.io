How to report a factual error, outdated resource or technical issue on Acting UK.

Report a correction

Please identify the page URL, the detail that needs correcting and a reliable source supporting the change. For directory updates, include the organisation’s official public information.

How to reach us

Use the Acting UK website issue tracker for public website corrections and technical issues. Do not include private personal information or confidential documents in a public issue. A dedicated editorial contact address has not yet been published.
