# Acting UK distribution

- Editorial agents commit to main on existing schedules. Generated feeds and calendar are maintained by scripts/generate-discovery.mjs; the distribution workflow runs on pushes and hourly at minute 23, with no AI calls. If generated files change it commits them and explicitly requests a Pages build. A denied build request is reported; no Pages settings changed.
- IndexNow uses one global endpoint; WebSub publishes three feeds. The distribution-state branch records hashes and responses, avoiding repeated successful submissions. Only exact live content is submitted. Acknowledgement is not indexing. Failed notifications are retried on subsequent runs. Check Actions for errors.
- News sitemap uses original publication dates, today and yesterday for date-only records. Standard sitemap retains older articles. RSS dates are preserved from the existing feed. Calendar lists run overlap, not individual performance times; casting requires deadline and applicationUrl.
- Search Console / Bing: ownership must be verified by the account owner or existing authorised access. Submit sitemap.xml and news-sitemap.xml once verified; check indexing and impressions. Flipboard: publisher approval/account setup not done, use /rss.xml when eligible. Newsletter requires opt-in subscribers and a consent-compliant service; not enabled. No paid API or new credentials.
